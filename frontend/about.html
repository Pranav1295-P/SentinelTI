1.1

Start witha Sample

An investigation usually starts with one suspicious file: an attachment, a dropped binary, something a user downloaded. Deciding whether it is dangerous, and why, is the first job.

SentinelTI does that first pass for you and records how it reached its answer. You still own the decision, with the evidence in front of you.

1.2

How SentinelReads a File

Magic bytes reveal the real type, whatever the extension claims. Hashes fingerprint it. Strings, headers, section tables and import tables expose what the code is built to do, and packers or high entropy show what it is trying to hide.

The file is only ever read, never run. Native parsers work in a throwaway process with resource limits and no access to secrets, so a hostile file can only break one tool call.

2.1

How an AgentThinks

Every agent follows the same LangGraph loop. The model chooses a tool from the task and the evidence so far, the call is validated with Pydantic, and a parser runs on the quarantined file. Only the parser's structured output moves forward.

LLM AgentChooses an available tool from the task and evidence
Tool CallingValidates input with Pydantic and runs the tool on the quarantined sample
Structured EvidenceTyped facts handed to the next agent
